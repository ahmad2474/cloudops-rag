# INC-1035: `DenyIMDSv1` SCP blocked launch of a legacy AMI

## Summary
Replacing the Tailscale subnet router instance failed with
`UnauthorizedOperation … explicit deny in a service control policy`. The launch template
lacked `metadata_options { http_tokens = "required" }`, which the new `DenyIMDSv1` SCP
(rolled out 2026-02-01) requires.

## Impact
Office access to internal tools degraded for 70 min (the old instance had already been
terminated by the replacement).

## Root cause
SCP rollout without inventory of launch templates lacking IMDSv2 enforcement.

## Remediation
Launch template updated; instance launched.

## Prevention
Config rule `ec2-imdsv2-check` run before SCP enforcement; `modules/acme-ec2` defaults
`http_tokens = "required"`.
