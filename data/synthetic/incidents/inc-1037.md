# INC-1037: Statuspage automation posted a test incident to customers

## Summary
Testing the `/incident declare` Slack workflow in `#inc-test` created a real Statuspage
incident ("Test — please ignore") visible to merchants for 8 minutes; 40 subscribers were
emailed.

## Root cause
The workflow's Statuspage integration had no sandbox mode.

## Remediation
Incident deleted; follow-up email sent.

## Prevention
Statuspage step gated on channel name prefix `#inc-` excluding `#inc-test`; sandbox page
for tests.
