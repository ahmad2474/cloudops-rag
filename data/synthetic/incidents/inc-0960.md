# INC-0960: ArgoCD staging sync loop caused by a mutating webhook

## Summary
A new Kyverno **mutate** policy added a default `topologySpreadConstraints` block to
Deployments. ArgoCD saw the live object differ from Git, re-synced, the webhook mutated
again — 40 syncs/min across staging, API server latency up, and Kyverno itself throttled.

## Impact
Staging deploys unreliable for 85 min; API server p99 2 s.

## Root cause
Mutation not reflected in `ignoreDifferences`; ArgoCD's diff considered it drift.

## Remediation
Policy disabled; re-enabled with an ArgoCD `ignoreDifferences` entry (`jqPathExpressions`
for the mutated field) and `RespectIgnoreDifferences=true`.

## Prevention
Mutating policies must ship with the ArgoCD ignore rule in the same PR (checklist item).
