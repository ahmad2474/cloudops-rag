# INC-0919: Near miss — RDS `publicly_accessible = true` caught by Checkov

## Summary
A PR to the staging data stack set `publicly_accessible = true` on `staging-identity-pg`
"to test from a laptop". CI failed on `CKV_AWS_17`; the PR was closed. Recorded as SEV-4
so the pattern is tracked.

## Why it matters
Even in staging this violates `database-security` §1 and would have exposed a database with
synthetic-but-realistic PII to the internet behind a security group.

## Prevention
- Reminder in `#eng-announce`: laptop access to staging databases goes through the Tailscale
  subnet router + Gatekeeper `namespace-admin`, not public endpoints.
- `modules/acme-rds` no longer exposes `publicly_accessible` as a variable.
