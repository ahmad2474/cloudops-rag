# INC-0928: Cluster Autoscaler fought the node group rollout during the 1.29 upgrade

## Summary
During the `general` node group version update, Cluster Autoscaler kept scaling the ASG
down (it saw the new, empty nodes as underutilised) while the managed rollout was adding
them. The rollout stalled for 75 min with repeated `PodEvictionFailure` events.

## Impact
No customer impact; upgrade window extended by 1 h 15.

## Root cause
The upgrade runbook step "scale Cluster Autoscaler to 0 during node group rollouts" was
skipped.

## Remediation
`kubectl scale deploy cluster-autoscaler -n kube-system --replicas=0`; rollout completed in
18 min; CA restored.

## Prevention
Runbook step made a hard gate in the change template. (Moot after Karpenter adoption in
2026-03, which handles drift natively.)
