# INC-1053: Karpenter node churn after disruption budgets removed

## Summary
A PR reformatting the Karpenter Terraform module dropped the `disruption.budgets` block
(and `consolidateAfter`) from the `general-spot` NodePool. Within minutes Karpenter began
consolidating aggressively during peak; nodes were replaced every 2–3 min and pods restarted
repeatedly.

## Impact
`payments-api` p99 480 ms for 50 min (limit 400); 0.2% errors from in-flight requests on
terminated pods.

## Root cause
Config regression; reviewers missed the removal in a large formatting diff.

## Remediation
Reverted; Karpenter settled in 5 min.

## Prevention
`kubectl get nodepool -o yaml` snapshot test in CI compares critical fields; formatting-only
PRs must be separate from functional changes.
