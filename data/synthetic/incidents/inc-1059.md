# INC-1059: DR game-day — ESO in us-west-2 pointed at the us-east-1 endpoint

## Summary
During the semi-annual DR exercise, with us-east-1 access blocked by an SCP simulation,
pods in `prod-usw2-a` failed to start because External Secrets Operator's `ClusterSecretStore`
had `region: us-east-1` (copied from prod values). Replicated secrets existed in us-west-2
but were never read.

## Impact
Game-day RTO 52 min instead of the 40 min target; no real customer impact.

## Root cause
Region-specific value shared across environments via a common values file.

## Remediation
`region: us-west-2` in the DR overlay.

## Prevention
Game-day checklist item; conftest rule flags `us-east-1` literals in `dr` overlays.
