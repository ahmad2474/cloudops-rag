# INC-1056: Atlantis plans failing — DynamoDB lock table write-throttled

## Summary
A monorepo-wide PR touched 40 stacks; Atlantis ran plans in parallel and the lock table
`acme-prod-terraform-locks` (provisioned 5 WCU) throttled `PutItem`. Plans failed with
`Error acquiring the state lock … ProvisionedThroughputExceededException`.

## Impact
Infra changes blocked 50 min.

## Root cause
Provisioned capacity sized for sequential use.

## Remediation
Table switched to on-demand capacity.

## Prevention
Atlantis `parallel_plan` limited to 8; lock tables on-demand in all accounts.
