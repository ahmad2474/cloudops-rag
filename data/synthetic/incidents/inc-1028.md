# INC-1028: Provider upgrade to `aws ~> 5.80` produced `tags_all` drift on 300 resources

## Summary
After bumping the provider, every plan showed `~ tags_all` updates because resources set
`acme:owner` both in `default_tags` and in resource `tags`. Reviewers could not see real
changes in 300-line plans; two PRs were held for a day.

## Impact
Infra change velocity; no runtime impact.

## Root cause
Known provider behaviour change for duplicated tags.

## Remediation
Removed `acme:*` from resource-level `tags` across modules (one mechanical PR).

## Prevention
Provider bumps get a drift dry-run in a scratch workspace first; `terraform-plan-drift` §3.
