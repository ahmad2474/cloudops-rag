# INC-0911: staging DNS for `*.staging.acme.internal` broken after VPC recreate

## Summary
Staging VPC was recreated to change its CIDR. The Route 53 private hosted zone association
pointed at the old VPC ID; every `*.staging.acme.internal` lookup returned `NXDOMAIN` in
the new cluster.

## Impact
Staging environment unusable for 45 min; two PR pipelines blocked. No prod impact.

## Symptoms
`nslookup ledger-pg.staging.acme.internal` → NXDOMAIN; public and cluster DNS fine.

## Root cause
The zone association lived in a different Terraform stack (`dns`) that referenced the VPC ID
by value rather than through a remote-state data source; recreation changed the ID.

## Remediation
Associated the zone with the new VPC (`aws route53 associate-vpc-with-hosted-zone`), then
fixed the `dns` stack to read the VPC ID from remote state.

## Prevention
Cross-stack references via `terraform_remote_state`/SSM parameters only; lint rule for
hard-coded `vpc-` IDs.
