# INC-1044: ledger-service OOMKilled at startup after a dependency added an in-memory cache

## Summary
A minor version bump of the internal `acme-fx-rates` library began preloading a full
rate history (~900 MB) at startup. With a 2 Gi limit, `ledger-service` working set reached
1.95 Gi immediately and pods were OOMKilled during the canary.

## Impact
Canary aborted automatically; no customer impact (stable version kept serving).

## Root cause
Dependency behaviour change; memory limit sized for the old footprint.

## Remediation
Limit 2 → 3 Gi; library configured with a 24 h window instead of full history.

## Prevention
Dependency bumps of internal libraries run the memory-profile job in CI; limit ≥ 1.5× profile.
