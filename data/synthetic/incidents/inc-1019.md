# INC-1019: checkout-web latency from CPU throttling

## Summary
A chart refactor reintroduced `limits.cpu: "1"` on `checkout-web` (Node cluster mode, 4
workers). Throttled periods hit 55%; SSR p99 rose from 210 ms to 900 ms during the lunchtime
peak. Same class as INC-0930.

## Impact
Checkout p99 SLO breached 65 min; conversion dip noted by Growth.

## Root cause
CPU limit on an exempt service; the standards exemption wasn't encoded as a check.

## Remediation
Limit removed; rollout.

## Prevention
Chart CI fails if `limits.cpu` is set for services in the exempt list.
