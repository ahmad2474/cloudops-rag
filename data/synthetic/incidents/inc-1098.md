# INC-1098: IRSA token exchange failing in the DR cluster — no STS endpoint

## Summary
The us-west-2 VPC's `sts` interface endpoint was removed by a cost-cleanup PR ("unused").
With no NAT route on the `private-data`-style DR node subnets, pods could not reach
`sts.us-west-2.amazonaws.com`; every IRSA call timed out.

## Impact
DR cluster unable to run AWS-integrated workloads for 50 min; discovered by the weekly DR
smoke test, not by customers.

## Root cause
"Unused" judged by traffic volume (DR is idle) rather than by dependency.

## Remediation
Endpoint recreated.

## Prevention
Endpoint set is defined once in `modules/acme-vpc` and identical across regions; cost
cleanups of endpoints require a Reachability Analyzer check from the DR cluster.
