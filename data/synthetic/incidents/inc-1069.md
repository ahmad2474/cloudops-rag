# INC-1069: Terraform 1.12 upgrade — inconsistent lock file

## Summary
Atlantis image bumped to Terraform 1.12. Stacks whose `.terraform.lock.hcl` was generated on
macOS (arm64 only) failed on linux with `Error: Inconsistent dependency lock file`.

## Impact
Infra changes blocked 70 min.

## Remediation
`terraform providers lock -platform=linux_amd64 -platform=darwin_arm64` committed for 18 stacks.

## Prevention
Pre-commit hook runs `providers lock` for both platforms; CI verifies.
