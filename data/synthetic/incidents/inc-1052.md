# INC-1052: checkout-web canary auto-aborted on a false positive

## Summary
Three consecutive `checkout-web` canaries aborted at the 10% step. The AnalysisTemplate
error-rate query divided by `sum(rate(http_requests_total[1m]))` filtered to the **canary**
pods only; with a single canary pod the denominator was tiny and any 5xx pushed the rate over
0.5%. The abort itself is safe (traffic returns to stable), but a security fix was delayed 80 min.

## Impact
Delayed deploy; no customer impact.

## Root cause
Analysis query not robust to low sample counts.

## Remediation
Query rewritten with a minimum request count guard (`> 200 requests in the window`) and a
5-minute range.

## Prevention
AnalysisTemplates unit-tested against recorded Prometheus fixtures.
