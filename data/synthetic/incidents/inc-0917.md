# INC-0917: `iam:PassRole` denied blocks `acme-secret-rotator` deploy

## Summary
Atlantis apply for the rotator Lambda failed:
`User: arn:aws:sts::111111111111:assumed-role/acme-prod-atlantis/... is not authorized to perform:
iam:PassRole on resource: arn:aws:iam::111111111111:role/acme-secret-rotator-exec`.
The apply had already created the new execution role and now needed to pass it to Lambda.

## Impact
Rotation Lambda ran on the old code for 1.5 h; a scheduled rotation at 10:00 used the old
version successfully. No user impact.

## Root cause
The Atlantis role's permission boundary (`AcmeWorkloadBoundary`) allows `iam:PassRole` only
for roles with path `/acme/workload/`; the new role was created at `/`.

## Remediation
Role recreated with path `/acme/workload/`; apply succeeded.

## Prevention
`modules/acme-lambda` sets `path` by default; Checkov custom check `CKV_ACME_003` enforces it.
