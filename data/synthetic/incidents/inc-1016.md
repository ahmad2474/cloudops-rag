# INC-1016: GuardDuty crypto-mining DNS finding from the dev cluster

## Summary
GuardDuty raised `CryptoCurrency:EC2/BitcoinTool.B!DNS` for a `dev-use1-a` node. Treated
as SEV-1 per policy until SecEng triaged: the lookup came from a developer's ephemeral
namespace running a third-party load-testing image that phoned home to a domain on the
threat list. No mining process; no credentials on the node beyond the node role.

## Impact
None. Downgraded to SEV-4 after triage (1 h 35).

## Root cause
Unvetted public image in dev (Kyverno `require-acme-ecr` is audit-only in dev).

## Remediation
Namespace deleted; image blocked in the pull-through cache denylist.

## Prevention
`require-acme-ecr` moves to enforce in dev with an allowlist of vetted public images via the
ECR pull-through cache; GuardDuty EKS runtime monitoring enabled in dev.
