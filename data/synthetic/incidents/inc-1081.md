# INC-1081: Developers lost `kubectl` view access after Identity Center group rename

## Summary
The Identity Center group `eng-developers` was renamed to `engineering-developers` for a
directory sync. The `AcmeDeveloper` permission set assignment moved with it, but the EKS
access entry mapping (`aws-auth`-style access entries keyed by role session name) referenced
the old group name in the principal ARN pattern. `kubectl get pods` returned
`Forbidden` for every developer in prod and staging.

## Impact
Developers blind for 70 min; on-call used Gatekeeper sessions as a workaround.

## Root cause
Access entries derived from a hand-written mapping instead of the permission-set role ARN output.

## Remediation
Access entries updated.

## Prevention
Access entries generated from Identity Center permission-set role ARNs in Terraform;
smoke test `kubectl auth can-i list pods --as=<dev>` in CI after IAM changes.
