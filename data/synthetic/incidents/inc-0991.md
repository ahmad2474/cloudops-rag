# INC-0991: WAF rule blocked legitimate merchant API traffic

## Summary
A new AWS Managed Rule group (`AWSManagedRulesSQLiRuleSet`) moved from COUNT to BLOCK.
Merchant API calls whose JSON metadata contained strings like `select * from cart` (a
retailer's product description) were rejected with 403.

## Impact
Three merchants (~2% of volume) received 403 on 30% of their requests for 65 min.

## Root cause
Rule set enabled in BLOCK without analysing the COUNT-phase sample for false positives on the
`metadata` field.

## Remediation
Rule scoped to exclude the `metadata` body path (`FieldToMatch` JSON body with exclusions);
returned to BLOCK after 24 h COUNT review.

## Prevention
WAF changes follow COUNT for ≥ 7 days with a false-positive report; merchants with
free-text fields documented.
