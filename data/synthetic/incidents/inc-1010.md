# INC-1010: reporting-api PDB blocked node rollout

## Summary
The `general` node group version update stalled on one node for 40 min: `reporting-api`
had `PodDisruptionBudget minAvailable: 2` with 2 replicas, so eviction was never allowed
(`Cannot evict pod as it would violate the pod's disruption budget`).

## Impact
Upgrade window extended; no user impact.

## Remediation
PDB changed to `maxUnavailable: 1`; rollout resumed.

## Prevention
Kyverno `require-pdb-for-multi-replica` now also rejects `minAvailable >= replicas`;
standard §5.
