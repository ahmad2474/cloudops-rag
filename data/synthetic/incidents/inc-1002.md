# INC-1002: EKS API server throttling from an operator's unbounded list/watch

## Summary
A newly installed cost-reporting operator listed all Secrets cluster-wide every 10 s without
a cache. API server request latency p99 rose to 1.8 s; ArgoCD syncs and kubectl timed out
intermittently; `apiserver_flowcontrol_rejected_requests_total` climbed for the
`workload-low` priority level.

## Impact
Deploys delayed ~70 min; no runtime impact.

## Root cause
Operator without informer cache; wide RBAC (`secrets` list cluster-wide).

## Remediation
Operator uninstalled.

## Prevention
Third-party operators require a review of RBAC scope and API call profile (`apiserver_request_total`
by user agent in staging for 24 h) before prod.
