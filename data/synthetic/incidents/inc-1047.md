# INC-1047: Ledger exports failing — KMS key policy dropped IRSA principal

## Summary
A Terraform refactor moved KMS keys into `modules/acme-kms`. The key policy template for
`alias/acme-prod-ledger` was rebuilt from a list of principals that omitted
`acme-prod-irsa-ledger-service`. The nightly export failed with
`AccessDenied … KMS.AccessDeniedException` on `PutObject`; `data-pipeline` reads failed
the same way.

## Impact
Reporting data for 24 Feb delayed 6 h; merchant statements regenerated.

## Root cause
Principal list not derived from the roles that actually use the key; plan reviewers saw a
large key-policy diff and approved it as "refactor noise".

## Remediation
Principal restored; export re-run.

## Prevention
Key policies built from IRSA role outputs (no hand-maintained lists); CI test asserts each
key's usage principals via `simulate-principal-policy`; plans touching KMS require SecEng review.
