# INC-0973: Drift — console SG change from INC-0963 reverted by Terraform

## Summary
The nightly drift report flagged an egress deny rule on `sg-prod-eks-node` added via the
console during INC-0963. A routine apply for an unrelated change removed it. No impact
(the merchant endpoint had long recovered), but it demonstrates the risk of console changes.

## Root cause
Emergency console change never captured in Terraform.

## Prevention
Incident checklist: "any console change gets a follow-up PR within 24 h" (added to
`incident-response`); drift report tags the IC of the incident window.
