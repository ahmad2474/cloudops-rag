# INC-1072: RDS Proxy connection pinning after session-level `SET`

## Summary
A `payments-api` release added `SET search_path` at connection checkout. RDS Proxy pins
sessions after session-state changes, so multiplexing stopped; `DatabaseConnectionsCurrentlySessionPinned`
rose to ~100% and the proxy exhausted its backend connections (`MaxConnectionsPercent 90`).
Clients waited on `ConnectionBorrowTimeout` (120 s).

## Impact
Payment latency p99 > 5 s for 55 min; 4% timeouts.

## Root cause
Session-level statement incompatible with proxy multiplexing.

## Remediation
Rollback; fix uses the role's default `search_path` (`ALTER ROLE … SET search_path`).

## Prevention
Proxy pinning alarm (> 10%); code review checklist for proxy-safe SQL (no `SET`, no
prepared statements with `DEALLOCATE`, no advisory locks across statements).
