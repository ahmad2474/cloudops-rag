# INC-1061: S3 lifecycle rule expired current ledger export objects

## Summary
A lifecycle rule intended for `tmp/` (expire after 1 day) was applied with prefix ``
(empty → whole bucket) on `acme-prod-ledger-exports`. Overnight, current versions of all
exports older than 1 day received delete markers. Reporting jobs failed with `NoSuchKey`.

## Impact
Reporting unavailable 2 h 45; **no data lost** — versioning was on; delete markers removed.

## Root cause
Terraform `filter {}` block with an empty prefix applies to all objects; reviewer assumed
"no filter = no match".

## Remediation
Rule removed; delete markers bulk-removed with `s3api delete-objects` on the marker
version IDs (script archived under `scripts/s3-undelete`).

## Prevention
Checkov custom check: lifecycle expiration rules require a non-empty prefix or tag filter;
`prevent_destroy` doesn't cover objects — documented.
